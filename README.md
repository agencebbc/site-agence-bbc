# Site de l'Agence BBC — Assurance & Banque

Site de l'agence d'assurance et de banque de Narbonne : présentation, contact et rubrique Conseils.

- Construire : `npm install` puis `npm run build` (résultat dans `dist/`)
- Avant le lancement : `npm run check:lancement`
- Règles de publication et charte éditoriale : voir `CLAUDE.md`
